# Python Algorithms & Object-Oriented Programming

This repository contains Python projects focused on algorithmic problem-solving, clean software architecture (OOP), and system automation.

## Projects Included

### 1. Budget Manager (`budget_manager.py`)
A command-line personal finance manager.
- **Concepts Used:** Advanced Object-Oriented Programming (Classes, `@property`, `__str__`, `__repr__`), JSON file handling for data persistence, `Enum` for menu structures, and data filtering.
- **Purpose:** To practice building scalable, maintainable software with a clean architecture.

### 2. Luhn Algorithm Validator (`luhn_algorithm.py`)
A script to validate credit card numbers using the Luhn Algorithm (Modulus 10).
- **Concepts Used:** String manipulation, list slicing, basic arithmetic, and algorithmic logic.
- **Purpose:** To practice algorithm design and data validation.

### 3. File Organizer (`file_organizer.py`)
A script that automatically organizes a directory by sorting files into designated folders based on their extensions.
- **Concepts Used:** File system operations (`os`, `shutil`), dictionary mapping, and automation logic.
- **Purpose:** To practice interacting with the operating system and writing practical automation tools.
- 
### 5. Chat Analyzer (`chat_analyzer.py`)
A simple text analysis tool.
- **Concepts Used:** String manipulation, dictionary counting, and basic censorship logic.
- **Purpose:** To practice text processing and string methods.

## Requirements
To run these scripts, you will only need standard Python 3 libraries (no external dependencies required).
